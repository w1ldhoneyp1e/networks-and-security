# Тесты

## 1. Автоматическая проверка

```bash
make -C dns test
```

Команда собирает программу и запускает временный UDP DNS-сервер на `127.0.0.1`
со случайным портом. Внешняя сеть не требуется.

Проверяются:

- корректный DNS-запрос без флага рекурсии;
- итеративный переход по referral и glue-записи;
- обработка DNS name compression в ответе;
- вывод конечной A-записи в обычном и отладочном режимах;
- обработка `NXDOMAIN` как ошибки.

## 2. Ручная проверка

После сборки выполните запрос к публичной DNS-инфраструктуре:

```bash
./dns/dns_resolver example.com A
./dns/dns_resolver example.com AAAA -d
```

В обычном режиме программа должна вывести только найденный адрес или адреса. В
режиме `-d` в `stderr` выводятся серверы и переходы между уровнями делегирования.

Для проверки ошибки можно запросить заведомо несуществующий домен:

```bash
./dns/dns_resolver definitely-not-a-real-name.invalid A
```

Ожидаются ненулевой код завершения и сообщение `host not found (NXDOMAIN)`.
