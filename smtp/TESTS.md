# Тесты

## 1. Автоматическая проверка

Из корня репозитория выполните:

```bash
make -C smtp test
```

Команда сначала собирает клиент, затем запускает временный SMTP-сервер на
`127.0.0.1` со случайным свободным портом. Внешняя сеть и учётная запись почты
не требуются.

Автотесты проверяют:

- полный SMTP-диалог от приветствия `220` до `QUIT`/`221`;
- обработку многострочных ответов;
- допустимый ответ `251` на команду `RCPT TO`;
- создание заголовков, CRLF и dot-stuffing;
- корректную остановку клиента после ошибки сервера `550`;
- проверку номера порта до подключения.

## 2. Ручная проверка с локальным сервером

В первом терминале запустите тестовый SMTP-сервер:

```bash
python3 -m aiosmtpd -n -l 127.0.0.1:2525
```

Если модуль отсутствует `python3 -m pip install aiosmtpd`.

Во втором терминале соберите клиент, создайте файл и отправьте письмо:

```bash
make -C smtp
printf 'First line\n.leading dot\nLast line\n' > message.txt
./smtp/smtp_client 127.0.0.1 2525 alice@example.test bob@example.test 'SMTP test' message.txt
```

Клиент должен вывести SMTP-сессию с кодами `220`, `250`, `354`, `250`, `221` и
строку `Message accepted by the SMTP server.` Сервер должен принять письмо без
ошибки. Строка `.leading dot` будет передана серверу как `..leading dot`, как
требует SMTP.

## 3. Негативная проверка

Передайте невалидный порт:

```bash
./smtp/smtp_client 127.0.0.1 0 alice@example.test bob@example.test 'Test' message.txt
```

Клиент должен вывести подсказку по использованию и завершиться с ненулевым
кодом, не пытаясь подключиться к серверу.
