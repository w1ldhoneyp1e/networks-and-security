# Тесты

Перед тестом соберите проект и запустите сервер по инструкции из `README.md`.
После проверок, которые завершают сервер, запустите его заново.

(в следующий раз я точно напишу автотесты)

## 1. Обычный обмен сообщениями

1. Запустите клиента.
2. Введите `67`.

Клиент и сервер должны вывести число клиента `67`, число сервера `50` и сумму
`117`.

## 2. Некорректный ввод

Запустите клиента и по очереди введите `0`, `abc`, `101`, затем `50`.

После первых трёх значений клиент должен сообщить об ошибке и снова запросить
число. После `50` он должен выполнить обычный обмен с сервером с результатом 50

## 3. Несколько клиентов одновременно

Одновременно запустите несколько клиентов, например 3, и введите в каждом
число от `1` до `100`.

Сервер должен обработать все подключения без падения. В статистике поле `total`
должно увеличиться на количество запущенных клиентов.

## 4. Таймаут клиента

В отдельном терминале выполните команду. Она подключится к серверу, но не будет
отправлять данные 11 секунд:

```bash
bash -c 'exec 3<>"/dev/tcp/127.0.0.1/5050"; sleep 11; exec 3>&-; exec 3<&-'
```

Сервер должен сам закрыть это соединение и вывести в лог ошибку приёма или
таймаут.

## 5. Проверка greacefull shutdown

Запустите клиента с флагом `--shutdown`. Он отправит серверу число `0`.

Сервер должен прекратить принимать новые подключения, завершить worker-потоки и
вывести `shutdown complete`.

## 6. Завершение по SIGINT

Нажмите `Ctrl+C` в терминале с сервером.

Сервер должен завершиться без падения и сообщить об освобождении ресурсов.

## 7. Нагрузочное тестирование

В отдельном терминале выполните команду. Она запустит 1000 клиентов, при этом
одновременно будут работать не более 32.

```bash
seq 1 1000 | xargs -P 32 -I{} bash -c \
  'value=$((($1 - 1) % 100 + 1)); printf "%s\n" "$value" | ./socket/client_app 127.0.0.1 5050 >/dev/null' \
  _ {}
```

## 8. Утечки памяти 

Вместо обычного запуска сервера выполните команду через Valgrind, затем в другом
терминале запустите несколько обычных клиентов и завершите сервер сочетанием
`Ctrl+C`

```bash
valgrind --leak-check=full --show-leak-kinds=all --track-fds=yes \
  ./socket/server_app 5050 2
```

В отчёте Valgrind не должно быть утечек памяти и незакрытых сокетов. Хороший
результат содержит строку:

```text
All heap blocks were freed -- no leaks are possible
```
